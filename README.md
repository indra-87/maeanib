# 매안초등학교 연구학교 보고회 안내 웹 앱

GitHub Pages(화면) + Supabase(내용·파일·소감 저장)로 동작합니다.
**내용 편집은 GitHub이 아니라 편집 페이지(`admin.html`)에서 합니다.**

```
index.html        첫 화면 (층별 안내 · 바로가기 · 당일 일정 · 자료실)
classes.html      공개수업 (교실 카드 → 수업 소개 · 수업안 · 한 줄 소감)
campus.html       주차 · 학교 공간 (3D 배치도, 교실 클릭 → 같은 수업 소개 창)
checkin.html      참관 확인 (소속 · 이름 · 손 서명 → 참관증 PDF/인쇄)
admin.html        편집 페이지 (공유 비밀번호)
space/3d.html     3D 뷰어
assets/           디자인 · 공통 기능 · 연결 설정(config.js)
```

## 편집 페이지 쓰는 법 (`…/admin.html`)

공유 비밀번호로 들어갑니다. 저장하면 바로 사이트에 반영됩니다.

| 탭 | 할 수 있는 일 |
|---|---|
| 수업 소개 | 교실을 눌러 내용 고치기, 수업안 PDF 올리기 / PDF 여러 개 한꺼번에 올리기(파일 이름에 `1-1` 같은 교실 번호) / 엑셀로 내려받기 → 고쳐서 불러오기 |
| 당일 일정 | 일정 줄 추가 · 순서 바꾸기 · 지우기 |
| 자료실 | 보고서 등 파일 올리기 또는 링크 적기 |
| 사이트 설정 | 연구 주제, 날짜, 참관 신청 링크·마감, **참관 확인 열기/닫기/당일 자동**, 참관증 문구, 직인 이미지 |
| 소감 관리 | 소감 숨기기 · 지우기 |
| 참관자 명단 | 참관증 받은 분 목록, 엑셀(CSV)로 내려받기 |
| 비밀번호 | 공유 비밀번호 바꾸기 (8자 이상) |

- 여러 분이 동시에 편집해도 됩니다. 수업 소개는 교실별로 합쳐서 저장되고, 일정·자료실·설정은 다른 분이 먼저 저장했으면 알려 줍니다.
- 비밀번호를 10분에 10번 넘게 틀리면 10분 동안 잠깁니다.
- 파일은 하나에 50MB까지입니다. 저장 공간은 ibgrow 프로젝트의 무료 1GB를 함께 씁니다.

## 데이터가 있는 곳 (Supabase · ibgrow)

| 이름 | 내용 |
|---|---|
| `maean_content` | 수업 소개 · 일정 · 자료실 · 사이트 설정 |
| `maean_comments` | 한 줄 소감 |
| `maean_checkins` | 참관증 발급 기록 |
| `maean_admin` | 편집 비밀번호 (암호화 값만) |
| 저장소 `maean` | 수업안 · 보고서 · 직인 파일 |
| 서버 함수 `maean-upload` | 편집 페이지의 파일 올리기 · 지우기 |

## QR 코드 팁

- 교실 앞: `…/classes.html#1-3` → 그 수업 소개가 바로 열림
- 층 안내: `…/campus.html#f3` → 3층 배치도
- 참관 확인: `…/checkin.html`
